# iPhone 收邮件通知教程

这个方案不需要 App。你只要让 iPhone 能及时推送 QQ 邮箱或系统邮件通知就行。

## 方式一：QQ 邮箱 App

1. 在 iPhone 上安装 QQ 邮箱 App。
2. 登录你的收件邮箱。
3. 打开 iOS `设置` -> `通知` -> `QQ邮箱`。
4. 打开 `允许通知`，把横幅和锁屏都开上。
5. 在 QQ 邮箱 App 内把新邮件提醒打开。

## 方式二：iPhone 自带邮件 App

1. 在 QQ 邮箱网页端开启 `POP3/IMAP/SMTP` 服务。
2. 生成 `16` 位授权码。
3. 在 iPhone `设置` -> `邮件` -> `账户` 里添加 QQ 邮箱。
4. 密码栏填授权码，不填 QQ 登录密码。
5. 打开 `邮件` 的通知权限。

## QQ 邮箱授权码

QQ 邮箱官方说明里写得很清楚：

- 授权码是第三方客户端专用密码
- 适用于 `POP3/IMAP/SMTP`
- 更改 QQ 密码后，授权码可能需要重新生成

## 推荐做法

如果你只想省事，直接用 QQ 邮箱 App 收信就行。  
如果你想把通知尽量稳定一点，用系统自带邮件 App + 推送也可以。

## 发件邮箱

发件邮箱和收件邮箱可以是同一个 QQ 邮箱。  
如果后面你想更清晰一点，再单独开一个发件箱也行。
